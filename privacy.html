Privacy Policy / プライバシーポリシー

Last updated: 2026-11-25

1. What this tool is

Fuji Tesou Uploader is a personal tool used only by the owner of the YouTube channel 「ふじ 手相鑑定」 to upload her own videos to her own channel. It is not offered to the public.

2. YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. Information we access, use and store

  • With the owner's permission (Google OAuth, scope youtube.upload), the tool uploads video files, titles and descriptions that the owner prepared herself, and sets a scheduled publication time.
  • The OAuth access/refresh token is stored only on the owner's own computer, in a file readable only by her user account. It is never sent anywhere except to Google.
  • The tool keeps a local log of the videos it uploaded (file name, upload date, scheduled date, video URL).
  • The tool does not read, collect, store or share any data about other YouTube users, viewers, comments or analytics.

4. Sharing

No information is shared with, sold to, or disclosed to any third party. Data is sent only to Google/YouTube to perform the upload.

5. Cookies

The tool runs on the owner's computer and does not use cookies or similar technologies. This website does not use cookies.

6. Revoking access and deleting data

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. To delete stored data, the owner deletes the local token file and the local log. Uploaded videos can be deleted in YouTube Studio. On request, all stored API data is deleted within 7 days.
